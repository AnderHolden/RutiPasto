🚀 Objetivo Central del Proyecto
Garantizar a la ciudadanía de Pasto el acceso democrático, rápido y gratuito a la información operativa de movilidad urbana (recorridos, sentidos de ida/retorno, horarios y paradas), funcionando de manera nativa en cualquier dispositivo sin requerir saldo ni plan de datos.
Contexto & Justificación

El Problema y la Propuesta de Valor

¿Por qué nace Rutas Pasto Offline y qué necesidad social resuelve?

⚠️ La Problemática en San Juan de Pasto
  • Brecha de Conectividad: Muchos usuarios (estudiantes, adultos mayores y trabajadores) no cuentan con datos móviles activos al esperar un bus en la calle.
  • Complejidad de Rutas: Con 23 rutas urbanas y diferencias marcadas entre IDA y RETORNO, los usuarios desconocen dónde transbordar o bajarse.
  • Dependencia de Servidores Centrales: Las apps tradicionales colapsan si el servidor se cae o no hay señal 4G en zonas periféricas (ej. Cabrera, Obonuco, Catambuco).
💡 La Solución Desarrollada
  • Tecnología PWA (Progressive Web App): Se instala directamente desde el navegador en Android, iPhone o PC sin pasar por Play Store ni ocupar espacio excesivo.
  • Autonomía Total sin Conexión: Almacena en la caché del móvil los datos y mapas necesarios para funcionar sin consumir ni un solo megabyte.
  • Información Rigurosa: Cero datos inventados; recopila paradas oficiales con códigos del SETP y coordenadas GPS exactas.
Ingeniería de Software

Stack Tecnológico 100% Nativo

Una arquitectura sin dependencias pesadas: máxima velocidad y longevidad.

🌐 HTML5 Semántico
Estructura limpia, accesible y optimizada para lectores de pantalla y navegadores móviles. Etiquetas semánticas nativas y meta-tags PWA para pantalla completa.
🎨 CSS3 Variables
Diseño Mobile-First con CSS Custom Properties. Soporta cambio dinámico de Modo Claro y Oscuro con persistencia en localStorage sin recargar.
⚡ JavaScript ES6+ Vanilla
Código puro y modular. Sin React, Vue o Angular. Cero tiempo de compilación y arranque instantáneo (<100ms) sin sobrecargar la memoria del teléfono.
🗺️ Leaflet 1.9.4 Local
El motor cartográfico y sus estilos están guardados localmente dentro del proyecto (assets/leaflet/). No depende de CDNs externas que puedan caerse.
⚙️ Service Worker & Cache
Estrategia Cache First en segundo plano. Intercepta todas las peticiones para entregar el contenido almacenado en el disco del usuario.
☁️ Cloudflare Edge
Alojamiento en Cloudflare Pages conectado a GitHub, con soporte de cabeceras seguras (_headers) para distribución global ultrarrápida con SSL.

Diccionario de Funciones (1/3)

Inicialización, Validación y Mapa

Funciones que gestionan la carga de datos y el motor cartográfico.

cargarRutas() Inicio / Datos
Lee el array global RUTAS_PASTO desde data/rutas.js y lo asigna al estado reactivo AppState.rutas. Si el archivo no existe o se corrompe, emite un error controlado para no romper la interfaz.
validarDatos() Control de Calidad
Ejecuta un diagnóstico exhaustivo en el navegador: verifica que existan las 23 rutas, que no haya IDs duplicados, que todas tengan origen, destino, paradas y que las coordenadas GPS estén dentro de la caja geográfica de Pasto (lat 1.10 a 1.30, lng -77.40 a -77.20). Muestra en consola ✓ 23 rutas cargadas y ✓ Datos validados.
inicializarMapa() Leaflet Core
Crea la instancia de Leaflet centrada exactamente en [1.213, -77.281] (Pasto) con zoom 13. Configura la capa base de OpenStreetMap y crea grupos de capas aislados (capaRutasTodas, capaRutaActiva y capaParadas) para manipularlas sin conflictos.
mostrarTodasLasRutas() Vista Global
Dibuja simultáneamente las 23 rutas en el mapa. A cada una le asigna su color oficial de la paleta COLORES_RUTAS y asocia eventos de clic para que al tocar cualquier línea del mapa se abra la ficha de esa ruta.
Diccionario de Funciones (2/3)

Recorridos, Sentidos y Paradas

Funciones que gestionan la interactividad entre el mapa y las rutas.

seleccionarRuta(rutaId, sentido = 'IDA') Controlador Principal
Oculta las demás rutas del mapa, limpia marcadores previos y orquesta la visualización de la ruta elegida invocando a mostrarRutaEnMapa(), mostrarParadas() y mostrarFichaRuta(), desplazando suavemente la vista del usuario al panel.
mostrarRutaEnMapa(ruta, sentido) Geometría
Obtiene el array de coordenadas GPS del sentido activo (coordenadasIda o coordenadasRetorno), traza la polilínea con grosor de 6px y ejecuta map.fitBounds() para hacer zoom automático y encuadrar todo el recorrido en la pantalla del dispositivo.
mostrarParadas(ruta, sentido) Marcadores
Recorre las paradas georreferenciadas y crea marcadores HTML circulares numerados (con verde para el origen y rojo para el destino). Cada marcador incluye un popup con el nombre de la parada, sentido y código oficial del SETP.
renderizarParadasLista(paradas, ruta, sentido) Lista Interactiva
Genera el listado desplazable debajo del mapa. Al hacer clic en cualquier parada de la lista, el mapa vuela suavemente (setView zoom 16) hasta ella y abre automáticamente su globo informativo.
mostrarSentido(nuevoSentido) Alternador
Conmuta el estado entre 'IDA' y 'RETORNO', redibujando en tiempo real las polilíneas, las paradas y actualizando la ficha técnica.
Diccionario de Funciones (3/3)

Buscador, Geolocalización y Modo Oscuro

Funciones que enriquecen la experiencia del usuario final.

normalizarTexto(texto) Filtro de Texto
Convierte cadenas a minúsculas y elimina acentos mediante descomposición canónica Unicode (normalize('NFD').replace(/[\u0300-\u036f]/g, '')). Permite que "narino", "NARIÑO" y "nariño" coincidan exactamente.
buscarRutas(query) Algoritmo de Búsqueda
Examina en tiempo real códigos (C10), orígenes, destinos y las más de 1.700 paradas. Incluye diccionario semántico para puntos neurálgicos de Pasto (UDENAR, CESMAG, Parque Nariño, Terminal, Hospital y Centro), detallando en cada tarjeta la razón de la coincidencia.
centrarEnUbicacion() GPS
Utiliza la API navigator.geolocation para ubicar al usuario. Coloca un marcador pulsante animado con círculo de precisión en metros y centra el mapa. Si el permiso es denegado, emite un aviso toast sin romper la aplicación.
inicializarTema() / activarModoOscuro() Apariencia
Detecta la preferencia del sistema operativo o lee localStorage para alternar el atributo data-theme="dark" en el elemento raíz, modificando instantáneamente todas las variables CSS de color.
Arquitectura Offline

Ingeniería PWA y Service Worker

Cómo se logra que la aplicación funcione 100% offline y como app nativa.

⚡ Ciclo de Vida de sw.js
1. Evento Install:
Descarga y precachea de forma individual y segura todos los recursos del núcleo (HTML, CSS, JS, Leaflet y dataset de rutas).

2. Evento Activate:
Elimina versiones obsoletas de la caché y reclama el control inmediato de las pestañas activas con clients.claim().

3. Evento Fetch (Interceptor):
Estrategia Cache First. Si no hay conexión, sirve el recurso desde la memoria del dispositivo.
🛡️ Solución a la Instalación Móvil (WebAPK)
El Desafío Resuelto:
Al instalarse en Android, el sistema abre la app como una ventana independiente que a menudo añade parámetros a la URL (ej. ?utm_source=homescreen).

La Solución Técnica:
Se implementó un interceptor de navegación con { ignoreSearch: true } y mapeo cruzado entre / e index.html, garantizando que el móvil arranque la app de inmediato sin mostrar nunca el error de "no puede acceder al sitio web".
